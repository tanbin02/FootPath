Foot-er-path — Pure HTML E-Commerce
=====================================

কোনো Node.js / npm লাগবে না।

কীভাবে চালাবেন:
1. সব ফাইল একটা ফোল্ডারে রাখুন
2. index.html ফাইলে ডাবল-ক্লিক করুন
   অথবা ব্রাউজারে টেনে আনুন

পেজগুলো:
- index.html     → Homepage
- shop.html      → সব প্রোডাক্ট
- product.html   → প্রোডাক্ট ডিটেইল
- cart.html      → কার্ট
- checkout.html  → অর্ডার
- admin.html     → Admin Dashboard

প্রোডাক্ট যোগ/এডিট:
  js/products.js ফাইল খুলে এডিট করুন

অর্ডার:
  Checkout করলে browser-এ সেভ হয়
  Admin পেজ থেকে CSV ডাউনলোড করে Excel-এ খুলতে পারবেন

GitHub Pages-এ হোস্ট:
  1. GitHub-এ নতুন repo বানান
  2. সব ফাইল আপলোড করুন
  3. Settings → Pages → Source: main branch
  4. কিছুক্ষণ পর লিংক পাবেন
